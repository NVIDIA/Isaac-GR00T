## Security

NVIDIA is dedicated to the security and trust of our software products and services, including all source code repositories managed through our organization.

If you need to report a security issue, use the private contact points below. **Do not report security vulnerabilities through public GitLab issues or merge requests.**

## Reporting a Potential Security Vulnerability

- Web: [Security Vulnerability Submission Form](https://www.nvidia.com/object/submit-security-vulnerability.html)
- Email: psirt@nvidia.com
- PGP: [NVIDIA public PGP key](https://www.nvidia.com/en-us/security/pgp-key)

Include the affected product and version or branch, vulnerability type, reproduction instructions, proof-of-concept if available, and potential impact.

See NVIDIA's [PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/) and [Product Security portal](https://www.nvidia.com/en-us/security/) for additional information.
